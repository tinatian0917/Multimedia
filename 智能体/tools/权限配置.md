# 权限配置（HR-20）

> 最小权限原则，每个组件只拿它必须的权限。

---

## 一、文件系统权限

| 目录 | 权限 | 说明 |
|------|------|------|
| 原始纪要目录（`demo/张三/` / `【按现场环境填：/data/interview-minutes/】`） | **只读** | 禁止任何写入、修改、删除 |
| 沙箱目录（`/tmp/hr20-sandbox/{candidate_id}/`） | 读写 | 所有中间产出（索引/分栏/交付物/轨迹）都在这里 |
| 状态目录（`/tmp/hr20-state/{candidate_id}/`） | 读写 | 只存 JSON 状态文件 |
| 缓存目录（`/tmp/hr20-cache/{幂等键}/`） | 读写 | 存幂等命中的索引 JSON |
| Skill 目录（`.trae/skills/...`） | 只读 | Skill 只读不写 |
| 脚本目录（`scripts/`） | 只读 | 脚本只读不写 |

**落地方式**（macOS）：
```bash
# 原始纪要目录设为只读
chmod -w demo/张三/
chflags uchg demo/张三/*.md

# 沙箱隔离
mkdir -p /tmp/hr20-sandbox/张三/
# 脚本运行时只在沙箱里写文件
```

| 权限 | 是否允许 | 说明 |
|------|---------|------|

## 五、运行时约束

| 约束 | 说明 | 落地 |
|------|------|------|
| **进程隔离** | 脚本在独立进程里跑，不许 fork 子进程去做其他事 | hr20.py 是单进程脚本 |
| **内存限制** | 单进程内存 ≤ 【按现场环境填：512MB】 | `ulimit -m 524288` |
| **执行时间限制** | 单任务 ≤ 【按现场环境填：5分钟】 | 外部超时器监控 |
| **目录逃逸防护** | 脚本只能访问配置好的 4 个目录（原始纪要、沙箱、状态、缓存） | 路径白名单校验 |
| **不执行用户输入** | 脚本不许 exec/eval 任何用户上传的文件内容 | 已实现（只做正则匹配，不做代码执行） |

## 六、护栏自动拦截（运行时强制）

| 拦截点 | 拦截方式 | 触发动机 |
|--------|---------|---------|
| 输出前最后扫描 | 生成交付物前全文搜索 G-01/G-02 关键词 | 命中即停 |
| 每步护栏快照 | STAGE_2/STAGE_3 结束时自动存快照 | 续跑前校验，有破就停 |
| 违规段落自动过滤 | split_fact_eval 里 has_violations() 检测 | 命中即跳过该段 |
| 幂等缓存校验 | 续跑时查幂等键 | 不一致 → 重新解析（不是拦截，是保守） |

## 七、异常兜底路径

| 异常类型 | 兜底动作 | 触发条件 |
|----------|---------|---------|
| 护栏检查失败 | 自动标红 → 转人工 → 发通知 | 任何护栏 G-01~G-05 不通过 |
| 工具重试到上限 | 自动停 → 转人工 → 发通知 | indexer 重试 2 次 / 语义处理重试 1 次后仍失败 |
| 转人工超时 | 自动标「超时未处理」→ 发升级通知 | 超过【按现场环境填：24h】 |
| 文件系统异常 | 自动停 → 状态文件里记 `failed` | 读/写权限问题、磁盘满等 |
