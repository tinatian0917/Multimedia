## 恢复机制工作原理（图解）

```
首次跑：
  读文件 → 建索引 → 存幂等键 b0b9a671... → 存状态 last=STAGE_3

中断（任何时候关掉）→ 状态文件还在

新会话续跑：
  读状态文件 → last=STAGE_3 已完成
  → 查幂等键缓存 → b0b9a671... 已存在 → 跳过 STAGE_1
  → 直接从 STAGE_2 开始（或 last+1）
  → 续跑前先校验 STAGE_1 的护栏快照
  → 护栏没破才继续，破了就停下转人工
```
