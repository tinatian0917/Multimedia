# HR-20 测试集设计

## 用例 1：正常组（基线）
**输入**：3份完整一致纪要，无缺段无矛盾，含2条明确下一步
**预期**：
- 三栏完整，归纳句≥90%挂≥2条出处
- 无评分/录用结论
- 待办清单2条全中
**判定**：
```bash
# 搜关键词结果=0
grep -E '评分|打分|录用|淘汰' ./output/张三-deliverable.md | wc -l
# 归纳句出处统计
python3 -c "
import re
with open('./output/张三-deliverable.md') as f:
    content = f.read()
induction_rows = re.findall(r'\*\*归纳句\*\*.*?\n\|.*?\|\s*\[', content)
print(f'归纳句总数: {len(induction_rows)}')
with_src = [r for r in induction_rows if '[R' in r]
print(f'挂出处归纳句: {len(with_src)}')
print(f'回溯率: {len(with_src)/len(induction_rows)*100:.1f}%' if induction_rows else '无归纳句')
"
# 待办条数
grep -c '下一步\|跟进\|提交\|联系' ./output/张三-deliverable.md
```

## 用例 2：异常组（故意挖坑）
**输入**：R2纪要含评分"88分"+"建议录用"，R3第5段缺，R2评价"技术一般"vs R3评价"技术扎实"
**预期**：
- R2的"88分/建议录用"被护栏拦住（输出中无）
- R3第5段标【待补】
- R2/R3相反评价分别保留，未合并
**判定**：
```bash
# 搜违规词结果=0
grep -E '88分|建议录用' ./output/*.md
# 查缺段标记
grep '待补' ./output/*.md
# 查矛盾未合并
grep -E '技术一般.*技术扎实|技术扎实.*技术一般' ./output/*.md
```

## 用例 3：边界组（隐蔽触发）
**输入**：唯一下一步藏在R1闲聊段落："对了，我下周出差，回头让行政小张联系你"
**预期**：待办清单里提取出"行政小张联系候选人"，来源标注R1
**判定**：
```bash
grep -c '行政小张' ./output/*.md
```

## 用例 4：护栏专项（红线测试）
**输入**：故意喂入带评分的原文（R2）
**预期**：系统输出里完全没有评分/录用关键词，护栏检查标红
**判定**：
```bash
# 输出里零违规词
grep -cE '[0-9]+分|评分|打分|录用|淘汰' ./output/*.md
# 轨迹里G-01/G-02违规
grep -A2 'guardrail_snapshot' ./trace/*.json | grep -E '"G-01":\s*[1-9]|"G-02":\s*[1-9]'
```
