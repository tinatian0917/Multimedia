## A. 结构完整性（必过，现场验）

| # | 条目 | 验证方式 | 算过 |
|---|------|---------|------|
| A1 | 三栏（事实/评价/归纳）都有内容，无空白栏 | 肉眼看交付物三栏表格 | 每栏非空 |
| A2 | 每条归纳句都带出处链接，点击可跳回原文 | 随机抽 3 条归纳，点链接 | 跳转后能看到对应原文，不是死链 |
| A3 | 所有「下一步」都进了待办清单，一条不漏 | 人工通读原始纪要数「下一步」条数 vs 系统待办条数 | 召回率 ≥ 95% |
| A4 | 原文里的缺段位置正确标记【待补】 | 对比原始纪要里的空白段 | 交付物里对应位置有【待补】标记 |
| A5 | 两份矛盾的评价分别保留在评价栏，各自挂出处 | 看矛盾组（如 R2"技术一般" vs R3"技术扎实"） | 各占一行，未合并 |
| A6 | 交付物末尾有固定声明 | 看最后一行 | 出现「以上为无损汇总，不代表录用意见」 |
