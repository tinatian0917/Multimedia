# 结构化输出定义（HR-20）

> 给下游读的固定字段格式，所有产出严格按这个结构。

---

## 一、输入结构（纪要索引）

```json
{
  "candidate_id": "string，必填，格式：姓名/岗位/唯一ID",
  "index_version": "string，必填，默认 v1.0",
  "total_paragraphs": "int，必填，原始段落总数（不含标题空行）",
  "missing_paragraphs": [
    {
      "round": "enum R1/R2/R3/R4/R5，必填",
      "paragraph_id": "string，必填，格式：R{n}-P{seq:03d}",
      "label": "string，必填，缺段内容的简短描述"
    }
  ],
  "conflict_groups": [
    {
      "type": "string，必填，固定值：'evaluation'（评价矛盾）",
      "words": ["string，必填，相反的两个评价词"],
      "paragraphs": [
        {
          "round": "enum，必填",
          "paragraph_id": "string，必填",
          "text": "string，必填，该段落前150字"
        }
      ]
    }
  ],
  "rounds": [
    {
      "round": "enum，必填",
      "interviewer": "string，必填，面试官姓名",
      "file_name": "string，必填，原始文件名",
      "paragraphs": [
        {
          "paragraph_id": "string，必填，格式 R1-P001",
          "seq": "int，必填，该轮次内的序号",
          "text": "string，必填，原封不动抄的段落内容",
          "content_hash": "string，必填，SHA256 前16位",
          "is_missing": "bool，必填，该段是不是缺段"
        }
      ]
    }
  ],
  "idempotent_key": "string，必填，幂等键",
  "created_at": "ISO8601 string，必填"
}
```

## 二、三栏汇总表输出（Markdown 表格）

### 事实记录栏字段
| 字段 | 格式 | 必填 | 说明 |
|------|------|------|------|
| 内容 | 原文直抄，≤200字 | 是 | 一个字不改 |
| 出处 | `📎 R{n}-P{seq}` | 是 | 点击可见原文 |

### 面试官评价栏字段
| 字段 | 格式 | 必填 | 说明 |
|------|------|------|------|
| 内容 | 原文直抄，≤200字 | 是 | 含主观判断词 |
| 来源 | `👤 {面试官} · R{n}` | 是 | 标注面试官姓名和轮次 |
| 矛盾标记 | 红色【待核】脚注 | 条件 | 该评价属于矛盾组时必填 |

### 归纳句栏字段
| 字段 | 格式 | 必填 | 说明 |
|------|------|------|------|
| 归纳文本 | 合并后的一句话，≤200字 | 是 | 从跨轮次重复事实里提炼 |
| 出处 | `🔗 出处×{n}：[R1-P001](url), [R3-P004](url)` | 是 | ≥2 条，点击跳转原文 |

---

## 三、待办清单输出（Markdown 表格）

| 字段 | 格式 | 必填 | 说明 |
|------|------|------|------|
| 待办ID | `T-{n:03d}` | 是 | 唯一标识 |
| 事项内容 | 原文直抄的约定内容，≤200字 | 是 | 从纪要里扫描关键词提取 |
| 约定人/轮次 | `{面试官} · R{n}` | 是 | 谁要做、哪一轮约定的 |
| 原文出处 | `[R{n}-P{seq}](url)` | 是 | 点击可见原文 |

---

## 四、护栏检查结果输出（Markdown 表格）

| 护栏项 | 结果 | 判定详情 |
|--------|------|---------|
| G-01 评分输出次数 | ✅ 0 / ❌ {n} | 正则说明 |
| G-02 录用结论输出次数 | ✅ 0 / ❌ {n} | 正则说明 |
| G-03 归纳句出处达标 | ✅ 达标率 / ❌ 达标率 | ≥90% 算通过 |
| G-04 矛盾未合并 | ✅ 是 / ❌ 否 | 矛盾段落分别保留 |
| G-05 原文覆盖次数 | ✅ 0 / ❌ {n} | 已过滤违规/元信息/缺段 |
| **总体** | ✅ PASSED / ❌ VIOLATED | 所有护栏全过才 PASSED |

## 六、轨迹记录字段（每次调用必记）

| 字段 | 格式 | 说明 |
|------|------|------|
| 调用时间 | ISO8601 | 收到请求的瞬间 |
| 入参摘要 | `candidate_id + 文件数量 + 轮次列表` | 不记完整参数，防膨胀 |
| 调用结果 | `success / error:E-XXX / 重试后成功` | 自动标记 |
| 索引产出摘要 | `解析份数、段落总数、缺段数、矛盾组数` | 自动统计 |
| 耗时 | 秒（保留1位小数） | 收到请求到返回的时间差 |
