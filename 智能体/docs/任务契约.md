# HR-20 任务契约：面试纪要三栏汇总与待办清单

> 版本: v1.0 | 日期: 2026-11-17 | 状态: 已签字

---

## 一、输入契约

| 字段 | 类型 | 必填 | 取值范围 | 说明 |
|------|------|------|---------|------|
| 候选人标识 | string | 是 | 非空，≤50字符 | 格式：姓名/岗位/唯一ID |
| 纪要文件列表 | array | 是 | ≥2 且 ≤10 | 每项含 round（R1/R2/R3）、interviewer、file_path |
| 纪要内容 | - | - | 允许：1份缺段、2份评价相反 | 这是测试噪声，不是异常 |

**硬限制**：纪要数量 <2 或 >10 时拒绝处理。

---

## 二、输出契约

### 三栏汇总表
每行为一个信息单元，固定三栏：
| 栏 | 内容 |
|----|------|
| 事实记录 | 原文直抄，每条末尾带出处链接 |
| 面试官评价 | 主观判断，标注「来源：轮次-面试官」 |
| 归纳句 | 合并≥2份纪要的事实，**每条≥2条出处**，点击见原文 |

### 待办清单
每项含：约定人 + 事项 + 截止日期（如有）+ 来源轮次。

**末尾固定声明**：「以上为无损汇总，不代表录用意见」

---

## 三、完成判定（5条全满足才算做完）

1. □ 三栏汇总表已生成，所有非缺段内容都被覆盖（原文漏段=0）
2. □ 每条归纳句出处链接可点击跳转
3. □ 系统输出中评分/录用结论关键词搜索结果=0
4. □ 待办清单条数=所有纪要里「下一步」约定条数（一条不漏）
5. □ 末尾固定声明已加

---

## 四、护栏（违反即停/待核/转人工）

| 护栏 | 自动检查方法 | 违反处理 |
|------|-------------|---------|
| 无损汇总 | 索引hash vs 原文hash | 不一致→标红转人工 |
| 不打分 | 搜 `[0-9]+分|评分|打分|等级|⭐` | 结果≠0→标红停 |
| 不下录用 | 搜 `录用|淘汰|建议录用|建议淘汰` | 结果≠0→标红停 |
| 事实-评价分栏 | 事实栏无主观词，评价栏无客观内容 | 串栏→标红待核 |
| 归纳挂出处 | 每条归纳出处数组长度≥2 | <2→标红待核 |
| 矛盾不合并 | 矛盾段落分别保留 | 合并→标红停 |
| 原文不覆盖 | 引用段数=总段数-缺段数 | 差>0→标红停 |

---

## 五、执行循环

```
Step1 读多份纪要（indexer工具建索引）
  → Step2 分栏抽取（规则匹配）
    → Step3 出处挂接与归纳（语义归并）
      → Step4 出汇总与待办（生成交付物）
        → Step5 人确认（发起人工打勾）
```

每阶段结束写检查点，存幂等键，可中断恢复。
