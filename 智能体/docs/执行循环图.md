# 执行循环图（HR-20）

> 一图看懂从输入到交付物的完整链路，可用于演示时对着讲。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           任务契约（只读一遍，后续全程自动）                    │
│                                                                             │
│  输入：候选人ID + ≥2份纪要文件路径                                            │
│  输出：三栏汇总表 + 待办清单 + 护栏检查结果                                    │
│  停止条件：5条护栏全过 + 7条完成判定全满足                                      │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ STAGE_1：读多份纪要（indexer 工具）                                          │
│                                                                             │
│  输入：candidate_id + minute_files[]                                        │
│  动作：解析文件 → 建段落唯一ID → 标记缺段 → 检测矛盾评价                         │
│  产出：结构化索引 JSON（段落ID+原文hash+缺段标记+矛盾组）                       │
│  护栏：参数校验（路径存在/轮次不重复/数量合法）                                  │
│  检查点：✅ 写入状态文件 + 幂等缓存（SHA256 candidate_id+文件hash+版本号）       │
│  异常：某份文件打不开 → 停下返回"请检查文档格式"                                │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ STAGE_2：分栏抽取 + 出处挂接 + 归纳                                           │
│                                                                             │
│  分栏规则：                                                                  │
│    事实 = 原文直抄（候选人原话、客观行为、技术细节，一个字不改）                  │
│    评价 = 含主观判断词（"好""一般""扎实""流畅"等），标注来源轮次+面试官          │
│  归纳规则：                                                                  │
│    ≥2份纪要重复的事实 → 合并成归纳句，挂所有原文出处                              │
│    单份纪要覆盖的事实 → 不归纳，直接进事实栏                                     │
│    矛盾事实 → 各自保留，不合并，加脚注"存在矛盾"                                  │
│  护栏：跳过违规段落（含评分/录用），但不修改原文                                 │
│  检查点：✅ 写入状态文件 + 护栏快照                                            │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ STAGE_3：出汇总与待办 + 最终护栏检查                                           │
│                                                                             │
│  汇总表：三栏 Markdown 表格（事实 | 评价 | 归纳+出处链接）                       │
│  待办清单：从所有段落里扫描"下一步/后续/请提供/回头"等关键词，每条挂原文出处       │
│  护栏最终检查（5项全过才标记 PASSED）：                                          │
│    G-01 评分输出次数 = 0                                                    │
│    G-02 录用结论输出次数 = 0                                                 │
│    G-03 归纳句出处 ≥ 2（达标率 ≥ 90%）                                       │
│    G-04 矛盾事实未合并                                                       │
│    G-05 原文覆盖次数 = 0（跳过的都是违规/元信息/缺段）                            │
│  固定声明：末尾自动加「以上为无损汇总，不代表录用意见」                          │
│  检查点：✅ 写入状态文件（STAGE_3 success）                                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 5：人确认（必须的人工环节，不许跳过）                                     │
│                                                                             │
│  发起人打勾确认交付物 → 流程结束 ✅                                             │
│  发起人返回修改意见 → 带着意见回 STAGE_2 或 STAGE_3 重新走                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 中断恢复机制（贯穿全链路）                                                     │
│                                                                             │
│  任何时候关掉 / 杀掉进程 → 状态文件自动记录 last_completed_stage + 幂等键        │
│  新会话启动 → 自动读状态 → 跳过已完成阶段（幂等键命中缓存）→ 从断点续跑             │
│  续跑时自动校验护栏快照，有破立刻停下转人工                                      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 关键决策节点（什么时候必须停/转人工）

| 节点 | 决策 | 停/转人工条件 |
|------|------|-------------|
| STAGE_1 | 纪要数量检查 | <2 或 >10 → 拒绝处理 |
| STAGE_1 | 文件解析 | 某份打不开 → 返回错误 |
| STAGE_2 | 护栏检查 | G-01/G-02 ≠ 0 → 停下标红 |
| STAGE_2 | 归纳出处 | <2 → 标【待核】等确认 |
| STAGE_3 | 护栏终检 | 任何一项不通过 → VIOLATED |
| 续跑 | 护栏快照校验 | 有破 → 不续跑，转人工 |
